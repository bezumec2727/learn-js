# Дневник ошибок

## 1. Скрипты PowerShell запрещены (22.11.2026)
**Ошибка:** `npm : Невозможно загрузить файл C:\Program Files\nodejs\npm.ps1, так как выполнение сценариев отключено в этой системе` (PSSecurityException)
**Что значило:** команда npm запускается через скрипт PowerShell (.ps1), а Windows по умолчанию запрещает запуск скриптов, чтобы случайно не выполнить вредоносный файл.
**Как починил:** `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned` — свои скрипты можно, скачанные только с подписью.
**Урок:** необхожимо знать, какие команды требуют какив прав и какие разрешения или условия выставлять, что бы позволить необхожимой команде выполниться.

## 2. node hello.js ничего не выводит (22.11.2026)
**Ошибка:** ошибки нет, просто пустой вывод.
**Что значило:** файл в VS Code не был сохранён (белая точка на вкладке), и Node выполнил пустой файл с диска.
**Как починил:** Ctrl + S, потом включил File → Auto Save.
**Урок:** всегда сохраняйся.

## 3. Cannot find module (22.11.2026)
**Ошибка:** `Error: Cannot find module 'C:\hello.js'`
**Что значило:** Node ищет файл относительно текущей папки. Я был в C:\, а файл лежит в C:\dev\learn-js\00-snaryazhenie.
**Как починил:** перешёл в нужную папку через `cd` или указал абсолютный путь.
**Урок:** не забывать, что компьютер видит только то, что находится в папке.

## 4. Пробел в пути (22.11.2026)
**Ошибка:** `cd C:\Program Files\nodejs` не сработала.
**Что значило:** PowerShell делит команду по пробелам и решил, что `Files\nodejs` — отдельный аргумент.
**Как починил:** взял путь в кавычки: `cd "C:\Program Files\nodejs"`.
**Урок:**команды пробелы не любят, это может все поломать

## 5. Папка не найдена при перемещении (22.11.2026)
**Ошибка:** `Move-Item : Не удается найти путь "...\Документы\learn-js", так как он не существует` и `mkdir : Элемент с указанным именем C:\dev уже существует`
**Что значило:** я уже переместил папку раньше, поэтому повторные команды не нашли, что перемещать и что создавать.
**Как починил:** проверил через `ls C:\dev\learn-js`, что всё уже на месте.
**Урок:** если что то не работает, возможно, оно уже сработало, просто я прошляпил

## 6. DNS не ответил (22.11.2026)
**Ошибка:** `DNS request timed out. timeout was 2 seconds.` (nslookup github.com)
**Что значило:** DNS роутера или провайдера не ответил вовремя. Сам GitHub был в порядке.
**Как починил:** спросил DNS Google напрямую (`nslookup github.com 8.8.8.8`) и повторил запрос. Это был разовый сбой.
**Урок:** это даже не ошибка, это просто сбой. Надо знать, что такое бывает, и иногда проверять просто во второй раз. Если во второй раз тоде самое, это может быть последовательность, а не случайность

## 7. Document в терминале Node выдает ошибку
**Ошибка**: Uncaught ReferenceError: document is not defined
**Что значило**: Такая команда как document не определена
**Как починил**: Никак, окружения DOM просто нет в терминале Node
**Урок**: Окружение в браузере и в терминале на компе разные
